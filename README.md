# Simple NFT Marketplace

A gas-optimized, non-custodial NFT marketplace developed for our final blockchain project at BNU.

## 👥 The Team
* Abdul Raffay Qasim
* Zakriya

## ⚡ Core Features
* **Non-Escrow:** Sellers keep NFTs in their wallets via `approve()`, saving huge gas fees.
* **Atomic Swaps:** Instant, simultaneous NFT and Ether transfer.
* **Security:** Reverts automatically on duplicate listings or incorrect payments.

## 🛠️ Tech
* Solidity ^0.8.20
* OpenZeppelin ERC-721
* Remix IDE
